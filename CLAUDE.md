# Быки News (bikinews.ru) — репозиторий сайта и автопостинга

Фан-сайт о ФК «Краснодар». Неофициальный, на русском языке. Только новости, связанные с «Краснодаром».

## Устройство
- `site-src/bykinews.html` — мастер главной: стили, шапка, блоки, данные матчей/таблицы (JS-массивы `table`, `upcoming`, `played`, `scorers`) и список «Главное» (`<ul class="feed">`).
- `site-src/build.py` → собирает `dist/` (index.html, news.html, matches.html, data/glavnoe.json, rss.xml, sitemap.xml + `site-src/static/*`).
- `site-src/matches_build.py` — данные и вёрстка страницы «Матчи» (PLAYED, UPCOMING).
- `site-src/squad_build.py` — страницы «Состав» (squad.html, данные SQUAD) и «Клуб» (club.html).
- `site-src/news_pages_build.py` — у каждого пересказа из «Главного» своя страница `<транслит-заголовка>-<id>.html` (для поисковиков): собирается сама, попадает в sitemap и RSS, на главной и в «Новостях» заголовки ведут на неё.
- `site-src/max_build.py` — служебная страница bikinews.ru/max.html: свежие пересказы в виде готовых постов для канала в MAX (кнопка «Скопировать пост», ссылки-слова). Собирается сама из «Главного», не индексируется.
- `.github/workflows/deploy.yml` — при пуше в `site-src/**` собирает и выкладывает на SpaceWeb по FTP (секреты FTP_*).
- `poster.py` + `.github/workflows/telegram.yml` — каждые 20 мин публикует новые пересказы из data/glavnoe.json в Telegram, дайджест в 12:00 и 20:00 МСК. `state.json` — что уже опубликовано, руками не править.
- `android/` — приложение «Быки News» для Android (пакет ru.bikinews.app, Java, WebView + нативная нижняя панель). `.github/workflows/android.yml` собирает подписанные APK/AAB (секреты ANDROID_KEYSTORE_B64, ANDROID_KEYSTORE_PASSWORD; versionCode = номер запуска), `android-check.yml` гоняет приложение на эмуляторе и кладёт скриншоты в ветку `android-screens`. Сайт в приложении узнаётся по `BikinewsApp/` в user-agent (класс `html.app` — прячет ссылки шапки). `site-src/static/.well-known/assetlinks.json` — отпечаток ключа подписи, не менять. Новости в приложении обновляются вместе с сайтом, новую версию выпускать не нужно.
- Автолента «Лента» на главной и вкладка «Издания» на странице «Новости» читают `data/news.json` в браузере; повторы одного сюжета от разных изданий склеивает функция `sameStory` (в `bykinews.html` и в `NEWS_JS` внутри `build.py`) — по общим смысловым словам заголовка и текста. Менять правило нужно в обоих местах сразу.
- На хостинге отдельно живут `news.php` (сбор ленты по cron), `data/news.json`, `data/archive.json`, `data/tg-config.php` — их в репозитории нет и деплой их не трогает.

## Как добавить новость в «Главное»
1. Найти свежие материалы именно о «Краснодаре» (не о соперниках). Проверять факты по 1–2 источникам.
   Перед добавлением прочитать верх ленты «Главное» (последние 3–4 дня) и убедиться, что о том же событии новости ещё нет. Одно событие — одна новость: если появились новые детали, дополнить существующую (и поправить время/заголовок), а не писать вторую. Сверять с тем, что уже есть в ленте и в статьях (`article_build.py`), числа, даты, имена и формулировки решения/штрафа/счёта; любое расхождение между изданиями проверять по третьему источнику, а не выбирать наугад. Писать, что нового по сравнению с прошлыми материалами, а не пересказывать заголовок.
2. Вставить `<li><article>…</article></li>` в `<ul class="feed">` в `site-src/bykinews.html` по времени публикации источника (новые сверху). Формат:
   `<time class="mono">12 окт<span class="msep"> · </span><br>09:00</time>` (без времени — только дата),
   `<div class="nb"><span class="tag">Матч|РПЛ|Кубок|Клуб|Состав|Мнение|Сборная|Болельщикам</span><h3>Заголовок</h3><p>Абзац 1</p><p>Абзац 2</p><a class="src" href="URL" target="_blank" rel="noopener">Источник: Издание ↗</a></div>`.
3. Текст — собственный пересказ своими словами, 2 абзаца, без копирования фраз; короткие цитаты в кавычках допустимы. Фото и видео чужие не вставлять.
4. Номер новости считается автоматически из ссылки и заголовка — у двух новостей не должно быть одинаковой пары «ссылка + заголовок».
5. `python site-src/build.py` — проверить, что собирается без ошибок; затем commit + push в `main`.

## После матча
- `played`/`upcoming`/`table`/`scorers` в `bykinews.html`, блок героя (счёт, «N место»), карточка ближайшего матча и обратный отсчёт.
- `PLAYED`/`UPCOMING` в `matches_build.py` (голы с минутами, удаления, статистика).
- `SQUAD` в `squad_build.py` (страница «Состав»): у каждого игрока `rpl` = (игры, минуты, голы, передачи, ЖК, КК) по Sports.ru (sports.ru/krasnodar/stat/) и `cup` = (игры, голы, передачи, ЖК) по протоколу кубкового матча (rfs.ru). Новичка, впервые вышедшего на поле, добавить (номер, дата рождения, страна); ушедших убрать. Обновить `SQUAD_UPDATED`. Для забивших задан ключ `g` — голы по матчам подтягиваются из PLAYED сами.
